Contact support

Email findexy.support@gmail.com for help, bug reports, and feature requests. You can find the app version in Settings → Diagnostics.

For a bug, use Settings → Help & support → Report a problem if available. The app prepares a report you can review before sending.

Please avoid sending private files or passwords. If a screenshot helps explain the issue, check it for personal information first.

Quick answers

Installation problems

Install Findexy from its Microsoft Store page and check for updates in Microsoft Store.

A file does not appear

Check the chosen locations, file type, and any active filters. In Settings, add the folder or rebuild its index if needed.

Pro is not recognized

Confirm you're signed in to Microsoft Store with the account that owns Findexy Pro. Then use the purchase check in Findexy's Settings.

Search inside a file

Content search is a Pro feature. Add the folder to indexed locations, enable content indexing, and allow indexing to finish.
